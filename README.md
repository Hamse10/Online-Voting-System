# 🗳️ ONLINE VOTING SYSTEM

## Overview
**ONLINE VOTING SYSTEM** is an online voting platform that enables authorized voters to cast their votes without visiting a physical polling station.  
A secure database is maintained to store the complete information of all registered voters.

In the ONLINE VOTING SYSTEM:
- Voters can easily exercise their voting rights online.
- Registration is required before voting and is handled by the **System Administrator**.
- Citizens must contact the administrator to submit their details for registration.
- After successful registration, a **secret Voter ID** is assigned to the voter.
- Using the Voter ID, voters can log into the system and access voting services.
- Invalid or incorrect details during registration will prevent voting access.

## Software Requirements

- **Operating System:** Any version of Windows NT family (4.0 and above)

- **Frontend:**
  - HTML5
  - CSS
  - JavaScript
  - Bootstrap

- **Backend:** PHP

- **Database:** MySQL

## Instructions

Follow these steps to set up and run the Online Voting System:

1. Install **XAMPP** on your system.
2. Download the project ZIP file or extract it using **WinRAR**.
3. Extract the files and copy the `voting management system` folder.
4. Paste the folder into the root directory where XAMPP is installed:  
   Example: `C:/xampp/htdocs` (or corresponding directory on your system).
5. Open **PHPMyAdmin** by navigating to: [http://localhost/phpmyadmin](http://localhost/phpmyadmin)
6. Create a new database with the name `votesystem`.
7. Import the `votesystem.sql` file located inside the `db` folder of the extracted package.
8. Run the project by visiting: [http://localhost/voting-management-system](http://localhost/voting-management-system) in your browser.
9. Use the following credentials to log into the admin panel:
   - **Username:** `admin`
   - **Password:** `admin123`
